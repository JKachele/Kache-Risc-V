0000_0000 - 0FFF_FFFF: DDR3 SDRAM (256MB) (RWX)
1000_0000 - 6FFF_FFFF: Reserved
7000_0000 - 7007_FFFF: BRAM (512KB) (RWX)
        Reset-Vector: 7000-0000
8000_0000 - FFFF_FFFF: IO
        8000_0000 - 8FFF_FFFF: Memory Mapped Registers
                8000_0000: mtime (RW)
                8000_0008: mtimecmp (RW)
        9000_0000 - 90FF_FFFF: QSPI Flash (16MB) (R)
        F000_0000 - FFFF_FFFF: Basic I/O and UART
                F000_0000: UART Data (RW)
                F000_0004: UART Control (R)
                        [8]: UART RX FIFO Data Available
                        [9]: UART TX FIFO Full
                F000_0008: Arty White LEDs (W)
